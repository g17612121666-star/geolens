# 第二轮：17 个大气、海洋与气候实验

日期：2026-09-20。范围为本轮分配的 17 个实验及 `shared/ocean-section.tsx`，没有改导航、品牌、课程分类、登录或发布设置。

本记录说明源码与科学验证范围；它不是对 17 个浏览器画面的最终验收。整站可见预览、桌面/手机检查由主任务统一进行。

## 逐项改动

| Lab | 本轮实体、材质与场景改动 | 时间与参数联动 | 仍然明确保留的科学限制 |
|---|---|---|---|
| atmosphere-layers | 在地球表面加入参考 3 km 的云图层及低层大气边缘散射体积，保留透明分层截面，避免将气体画成实心外壳。 | 静态参考剖面，没有虚构时间。Lapse rate 改温度曲线，True scale 改大气厚度，Explode 改分层位置。 | 云图不是实时天气；大气边界为参考高度。光学晕是外观近似，不是辐射传输计算。 |
| carbon-cycle | 五种储库有不同物态：稀薄气体与放大的分子标识、透明体积里的真实分枝阔叶树、带反射水纹的海水、沉积/化石燃料岩体及层理。外层球体仍编码预算体积。 | `t` 同时改储量、球体体积、转移示踪位置；树与分子不是额外的碳计数。 | 继续清楚标为虚构闭合预算；球体是数量符号，不是实际地理形状。 |
| climate-types | 删除锥体针叶树与多面体树冠。使用有树皮、分枝、针叶/阔叶几何的实例化林地；沙漠具有陡缓坡和细沙纹。 | 静态长期气候分类；Family 即时切换栅格、参考城市与相应生物群落。 | 栅格为 Beck 等人的长期分类；小景是独立的示例植被，不是该城市实测植被。 |
| cyclone-anticyclone | 地面改为草地材质；低压出现有厚度的凝结云团，沿辐合轨迹向内并升高。保留真正的冷/暖锋地面线，不把它们换成热带眼墙。 | `t` 控制空气与云团的位置；南北半球改变转向，高低压改变辐合/辐散。 | 路径与云量是运动学示意，不是天气预报；高压不等于绝无低云。 |
| energy-budget | 辐射通路增加连续传播的波束，保留共同通量刻度的方向标识及全球平均守恒；波束与平衡关系同时可见。 | `t` 决定波束相位；Albedo 与 Greenhouse 即时改变通量/平衡温度。 | 波间距和传播速度不表示真实电磁波长或光速；仍为短波透明的灰色单层近似。 |
| enso | 上层海水加入反光水面；暖水上升区出现体积对流云与降水丝；增加跨剖面的连续空气输送束。 | `t` 驱动示踪、降水与光学流动；ENSO 参数同时改温跃层深度、上升位置、贸易风强度与温度。 | 海温/深度状态是明确规定的教学输入，不是 ENSO 指数反演，也不计算降水量。 |
| fronts | 将六个单球云符号换为有厚度的云体与成片下降雨丝，地表有土壤/植被纹理。保留两种真实不同的锋面坡度。 | 云与降水的空间位置随 `t` 对应锋面推进和锢囚；暂停后不会偷偷继续下雨。 | 云底和降水是结构示意，非微物理模型；True scale 保留同一几何比例。 |
| ocean-currents | 地球使用地形法线、海洋反光和昼夜照明；海流从逐点跳跃的粒子改为连续插值示踪与多股流丝。 | `t` 连续改变路径位置，切盆地改变地理路线；回拨可复现同一位置。 | 路线、宽度与速度都是放大的教学符号，不冒充实测流速/卫星洋流。 |
| rain-shadow | 中央讲解剖面保持原函数；非中央坡面增加侧脊和侵蚀沟谷。迎风低坡偏绿、背风偏干褐、山顶偏裸岩。针叶林具有树皮和针叶细节，云体增加垂直厚度。 | `t` 驱动气团与降水；Ridge/RH 同步改凝结判断和读数。中央 `h(x)`、讲解路径与温湿度计算未被装饰改变。 | 树与云仍明确是放大的环境示意；不是地形测绘、实况云场或降水预报。 |
| storm-surge | 自由水面使用具有反射水纹的真实水材质，截面仍透明可读。闭合岸界改为分段岸顶/岩体，加入代表给定风向的通风纹线。 | 静态稳态平衡，不虚构时间。Wind/Depth/Pressure 直接改自由面、风场显示与数值。 | 保留 100 km 平底陆架与闭岸边界；新岸顶不是地形数据，不计算淹没、浪高、潮汐或风暴演变。 |
| thermal-circulation | 海面改为水纹反射；陆地为草地；删除锥体树，换实例化针叶林与树皮。 | `t` 是课堂本地小时，同步热力对比、环流方向、示踪和水面光学相位。 | 温度曲线与环流速度是规定值；树和建筑为放大环境参照。 |
| thermohaline | 海水自由面、深层输送丝和透明水箱强化体积感；密度水团从中部释放，较轻水团也能明确上浮。 | `t` 控制上下两支流动和水团位移；等密度水团不动，重/轻水团向相反方向。 | 线性密度式不是 TEOS-10；水团是示踪标识，真实海水会混合。沉降速度与 AMOC 强度均未被计算。 |
| three-cell | 增加随 ITCZ 迁移的立体凝结云带。云团采用一次实例绘制，不将天气单元替换成一张平面环带。 | `t` 同步年内 ITCZ 纬度、云带位置与三圈示踪；True scale 隐去放大云团。 | 云带是纬向平均思想的结构示意，不是观测云图；Ferrel 仍标为涡旋维持的间接环流。 |
| tides | 新的较大地球/月球近景、高分辨率潮汐势包络和赤道等势轮廓。月面复用 NASA LROC 4K/LOLA 真实地形材质；地球自转可见。 | `t` 同时改月球方向、地球自转、月相与包络；月距补充正确 `r⁻³` 强度关系；True scale 恢复天体大小/距离同尺度。 | 蓝色是人为放大并外移的势符号，不是实海水壳层；没有地方潮时、潮高或潮汐预报。 |
| tropical-cyclone | 眼墙和雨带的三维云片按所在半径的理想风速移动；海面出现反射/细水纹。切片开口固定在空间中，云片穿过时仍正确剔除。 | `t` 驱动云片和同一理想风场中的粒子，两小时示意时间；Intensity/SH 改速度/转向。 | 风暴结构依然是理想稳态涡旋；没有云微物理、降水强度、增强过程或路径预报。 |
| tsunami | 保留正确海床剖面和同一垂直放大倍数，新增水面光学细节、清晰海床截面线及随波包移动的水深标尺。 | `t` 同步源区位移、传播波面、波包位置及深度标尺；不是只更新图表。 | 光学细纹不增加波高；海底形状、波高、速度和 Green 定律仍取自第一轮科学模型。不增加未经计算的破碎/上岸/洪水动画。 |

## 共同约束与实现

- 所有新增运动都来自 `useLabControls.t`。没有加入自己的 `Date.now`、`performance.now` 或独立时钟。播放、暂停、回拨与拖动使用同一课堂时间。
- 云、雨丝与流束使用确定性几何。`NaturalTree`/`PlantStand`、`TerrainMaterial`、`FlowWaterMaterial` 由主任务提供；多棵树改用两个实例化绘制的 `PlantStand`。
- `shared/ocean-section.tsx` 只增加位于模型原自由面上的光学表层；没有人为给水面加高度。岩床、体积边界与科学计算维持同一刻度。
- 复杂密度式与 `1/r³` 使用 `.formula`；正文语气和普通字体不变。
- 新增局部 helper：`atmosphere-layers/weather-volumes.tsx`、`wind/advection.ts`、`thermohaline/transport.ts`、`tides/tidal-potential.ts` 与 `tides/tidal-globe.tsx`。
