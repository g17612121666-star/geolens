## 模型与材质
- 岩石：世界坐标照片映射，减少拉伸和重复布纹；保留已认可的海岸与河流效果。
- 冰川：岩壁细节、散布针叶林、冰体流向；冰斗由封闭感碗形改为开放洼地，冰缘收尖，保留刃脊和角峰关系。
- 喀斯特：不规则节理、封闭岩层与洞穴剖面、附着的洞穴沉积。
- 水循环及流域：自然岸线水库、取水与水面联动、散布植被和地表细节。
- 火山：不同黏度端元与裂隙控制保留；喷发柱由透明球串改为渐扩体积烟羽。
- 热带气旋：连续眼墙、可切开的云体、半球及时间联动；修复透明海面错误遮住雨带。

- 岩石循环、洋流、雨影、地图投影：矿物颗粒、曲线圆滑、山体细节和初始视角改进。

## 本地复现
1. 在此目录运行 `npm run dev`，访问 `http://127.0.0.1:8080/`。
2. 右上角语言与外观：选简体中文，分别查看日间、夜间与系统模式。
3. 进入 `/explore` 搜索河流；`/glossary` 搜索曲流；`/atlas` 搜索并选择日本。
4. `/lab/tropical-cyclone` 切半球、拖时间和剖面；`/lab/volcanoes` 调黏度/气体；`/lab/glaciers` 切冰斗；`/lab/plate-boundaries` 切边界剖面。
5. `/teachers/rivers` 复制大纲并打开课堂环节。普通滚轮滚页，Ctrl＋滚轮缩放内嵌模型/图片。
6. `npm run typecheck`；`node scripts/test-science.mjs`；`node --test --test-isolation=none scripts/preferences-i18n.test.mjs`。
7. `npm run build` 后 `npm run preview -- --host 127.0.0.1 --port 8081` 检查正式构建。
