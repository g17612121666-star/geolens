## Scientific image assets

Added only measured/official image inputs:

- `public/textures/planets/moon-lroc-4k.jpg` — NASA SVS 2019 LROC colour mosaic, 4096×2048.
- `public/textures/planets/moon-lola-height.png` — NASA LOLA gridded height, 4096×2048 browser derivative. Encodes −12 to +12 km about the 1737.4 km reference sphere; source range −8.9815 to +10.6855 km. 8-bit height quantisation is approximately 94 m; this is a globe-scale visualisation, not a local landing-site DEM.
- `public/textures/planets/moon-terrain.source.json` — original URLs, SHA-256 hashes, credit, reference radius and scaling. [NASA SVS CGI Moon Kit](https://svs.gsfc.nasa.gov/4720/).
- `scripts/prepare-lunar-terrain.py` — reproducible TIFF-to-browser conversion. Download cache is in ignored `artifacts/lunar-source-data`, not runtime assets.

No synthetic photograph, generated landscape photo, new diagram-labelled-as-photo, or false ancient topography was added. The small teaching-map and illustrative material details are 3D/map-rendering resources, not photography replacements.
